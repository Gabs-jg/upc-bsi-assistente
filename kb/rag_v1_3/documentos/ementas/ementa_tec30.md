### TEC30 — Programação Web II

**Carga total:** 60 h (4 créditos). **Distribuição:** teórica 15 horas; prática 45 horas; extensão -. **Pré-requisito:** TEC21, TEC23.

**Ementa:** Linguagens de programação para back-end web. Persistência, validação e segurança de dados. Formatos para estruturação e intercâmbio de dados. Contêineres web. Frameworks para back-end.
